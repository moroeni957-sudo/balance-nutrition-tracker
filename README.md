# Баланс питания и активности

Адаптивное HTML5-приложение для расчёта пищевой ценности, энергозатрат и дневного баланса калорий с синхронизацией через Google Drive.

## Готовый сайт

https://moroeni957-sudo.github.io/balance-nutrition-tracker/

Репозиторий: https://github.com/moroeni957-sudo/balance-nutrition-tracker

## Возможности

- расчёт калорий, белков, жиров и углеводов для порции;
- профиль пользователя и расчёт энергозатрат;
- архив записей по датам;
- график баланса за разные периоды;
- импорт и экспорт дневных JSON-файлов через Google Drive;
- адаптивный интерфейс для компьютера, планшета и телефона.

## Локальный запуск

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

Затем откройте `http://127.0.0.1:8765/`.

## Google Drive

Приложение использует scope `drive.file`. Access token хранится только в памяти вкладки и не записывается в репозиторий или `localStorage`. API-ключ ограничен Google Picker API и разрешёнными адресами сайта.

Кнопка **Экспорт** создаёт или обновляет файл `Меню и активность YYYY-MM-DD.json`. Кнопка **Импорт** читает все JSON-файлы проектной папки и обновляет локальный архив и график.

## Хранение данных

Основные данные сохраняются в `localStorage` конкретного браузера. Для переноса между устройствами используйте Google Drive: сначала **Экспорт** на исходном устройстве, затем **Импорт** на другом.

Локальная Python-версия `app.pyw` не публикуется и остаётся в рабочей папке для справки.
