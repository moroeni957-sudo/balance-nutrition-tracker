# Исходные базы состава продуктов

Основные официальные наборы скачаны 14 августа 2026 года. Разрешённая к повторному использованию таблица школы №65 добавлена 20 августа 2026 года.

## Назначение наборов

- **Уровень 1:** `usda-foundation-2026-04-30-json.zip` и `usda-sr-legacy-2018-04-json.zip` — базовые продукты и проверенные справочные значения.
- **Уровень 2:** `usda-fndds-2021-2023-json.zip`, `ciqual-2025-eng.xlsx` и `bls-4.0-2025-de.zip` — приготовленные продукты, блюда, выпечка, сыры и различные способы обработки.
- `ciqual-2025-methodology-eng.pdf` — официальная документация CIQUAL 2025.

Сборщик оставляет только позиции с однозначным русским названием, нормализует КБЖУ на 100 г и устраняет совпадающие итоговые названия. В опубликованной сборке включено 387 позиций уровня 1 и 1 045 позиций уровня 2. Разные части продукта и способы приготовления сохраняются как самостоятельные позиции, если их можно корректно назвать.

Отображаемые названия создаются консервативными правилами из контролируемого русского словаря. Старый машинный словарь `translations-en-ru.json` не участвует в сборке: неизвестные, брендовые и сомнительные строки удаляются, а не транслитерируются. Точные русские дубли не получают искусственных суффиксов и исключаются.

Файл `curated-regional-foods.json` содержит 96 блюд русской и кавказской кухни со средними КБЖУ по типовой рецептуре. После сборки обязательна проверка `python audit_food_database.py`: она контролирует русский язык названий, отсутствие известных псевдопереводов и дублей, диапазоны КБЖУ, согласованность энергии и наличие ключевых региональных блюд.

Локально подключена официально предложенная сайтом «Мой здоровый рацион» скачиваемая офлайн-таблица: <https://health-diet.ru/table_calorie/>. Из старого Flash-проектора извлечён только встроенный SWF без запуска EXE. После удаления пустых и известных ошибочных строк источник дал 1 452 уникальные позиции; при точном совпадении русского названия эта таблица имеет приоритет. Сгенерированный `food-database.js` помечен `LOCAL-ONLY` и не должен публиковаться на GitHub без отдельной проверки права на распространение.

Для GitHub Pages предусмотрена отдельная сборка без источников, для которых не подтверждено право на публичное распространение:

```powershell
python build_food_database.py --public --output ..\.github-publish\food-database.js
python audit_food_database.py --database ..\.github-publish\food-database.js
```

Дополнительно обработана [таблица калорийности школы №65](https://xn--65-6kc3bfr2e.xn--80acgfbsl1azdqr.xn--p1ai/?section_id=36): её страница разрешает использование материалов при активной прямой ссылке. Из 316 исходных строк 149 добавили новые названия в публичную сборку после строгой проверки КБЖУ и удаления пересечений. Таблица подключена последней, поэтому любая уже существующая позиция имеет приоритет. Активная ссылка на источник показывается в окне каталога.

Не импортировались PBProg, PDF «Печерки», «Сочетайзер», CaloriX и «Таблица калорийности»: опубликованные условия не дают проекту необходимого разрешения на массовое копирование и повторное распространение каталога либо требуют отдельного согласия правообладателя. Локальное использование проекта не отменяет этих ограничений.

## Источники и условия использования

- USDA FoodData Central: <https://fdc.nal.usda.gov/download-datasets/>. Данные опубликованы как CC0 / public domain.
- Anses-Ciqual 2025: <https://ciqual.anses.fr/cms/en/2025-anses-ciqual-table>. При повторном использовании необходимо указывать источник и версию: `Anses. 2025. Ciqual French food composition table`.
- German Nutrient Database BLS 4.0: <https://blsdb.de/download>. Набор опубликован по лицензии CC BY 4.0; при распространении необходимо указать источник.
